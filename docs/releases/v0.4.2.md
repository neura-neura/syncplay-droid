## What changed

- Fixed the MPV video output path that could leave playback audio-only or permanently black. The
  player now uses a Compose-managed external surface and forwards size changes without tearing
  down the active MPV output.
- Improved subtitle sizing across orientations. Size 27 is the landscape reference, while portrait
  windows reduce it proportionally to the available device width. Untouched legacy size-38
  preferences are migrated automatically.
- Fixed the GothamPro CSS preset. Android now loads the normal and italic faces for weights 300,
  400, 500, 700, and 900, applies the selected weight, validates downloads before caching them,
  and restores the private cache on later offline launches. The first load still requires network
  access; GothamPro binaries are not bundled in the APK.
- Reworked playback time and controls. Time is shown live as `HH:MM:SS / HH:MM:SS`; tapping it
  toggles elapsed and remaining time. Controls now hide during playback, remain visible while
  paused or seeking, and return when the video is tapped.
- Added regression coverage for visible MPV surface output, control visibility, time formatting,
  portrait subtitle scaling, GothamPro weight registration, Android 6 compatibility, and offline
  font-cache restoration.

## Compatibility

- Android 6.0 (API 23) or newer.
- MPV remains the sole playback engine.
- Compatible with desktop Syncplay clients regardless of the player used on the desktop side.

## Verification

- Unit tests, Android Lint, and debug APK assembly pass.
- GothamPro loading, weight selection, cache restoration, and visual rendering pass on API 23 and
  API 37 emulators.
- The APK was installed successfully on both API levels.
